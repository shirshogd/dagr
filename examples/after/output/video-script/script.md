# Script: Reading a pull request

[Hook] You have been asked to "take a look at the PR". Here is what to look at.

[Part 1] The title and the description tell you what changed and why.
[Part 2] The file list shows where. Start with the files you recognise.
[Part 3] Red lines are removed, green lines are added. That is the whole trick.
