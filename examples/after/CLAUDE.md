# Nora's content studio

Solo creator. One weekly video, one weekly newsletter. Topics: practical programming for designers.

## Rules

- Read `CONTEXT.md` to find the workflow for a job. Load only the files its stage names.
- Voice: friendly, concrete, no jargon without a one-line explanation. See `knowledge/voice.md`.
- Never publish. Drafts only; Nora posts by hand.
- Past work lives in `output/`. Look there before writing something new.
